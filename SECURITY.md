# Security policy

Pi Desktop currently supports the latest `0.2.x` preview release. Security fixes may also be
backported to `0.1.x` when practical, but only the newest preview receives routine fixes.

Do not disclose suspected vulnerabilities in a public issue. Report them through a private GitHub
security advisory at:

https://github.com/Inas1234/pi-desktop/security/advisories/new

Include the Pi Desktop version, Pi version, Windows version, reproduction steps, and impact. Remove
API keys, provider tokens, credentials, session contents, and private project paths before attaching
logs or screenshots.
